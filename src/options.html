Mathegym Helper

Settings for the free AI via Google AI Studio (Gemma 4 and Gemini).

Set up the free AI

  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. Click Create API key and copy the key.
  3. Paste it here and click Save and verify.

Models and usage today

ModelRequests todayStatus

Automatic mode uses the first available model in this list. When a daily quota is used up, the next model takes over. Rough numbers from Google AI Studio: about 1,500 requests per day for each Gemma 4 model, a few hundred for Gemini Flash-Lite and about 20 for Gemini Flash. The quotas reset at 09:00 (midnight Pacific time).

Staying free and privacy

Do not enable billing for the Google project. Then the key can never cost money: when the quota is used up, Google only reports a limit.

Only the task text, field information and, if you want, an image of the task area are sent. According to the Gemini API terms, Google does not use this data for training for users in the EEA, Switzerland and the UK. The key is stored only in this extension; Mathegym cannot read it.

Usage: click Solve next to a result field or press Alt+L. Simple tasks are calculated without AI. Nothing is ever submitted automatically.
